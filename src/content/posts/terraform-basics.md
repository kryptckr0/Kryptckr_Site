# Terraform : décrire l’infrastructure avant de la déployer

L’Infrastructure as Code transforme une configuration implicite en code relisible et versionné.

## Le plan comme outil de réflexion

Avant d’appliquer, Terraform montre les changements envisagés. Cette étape crée un espace pour relire, challenger et sécuriser une modification.

L’état doit être protégé, partagé correctement et traité comme une donnée sensible. Automatiser ne dispense jamais de comprendre ce qui sera créé.
