# Les premières habitudes de hardening Linux

Le hardening commence rarement par une solution spectaculaire. Il commence par savoir ce qui écoute, qui a accès et ce qui doit réellement rester actif.

## Une checklist opérationnelle

Mises à jour, comptes, clés SSH, services exposés, permissions et journaux forment une base concrète.

Le plus important reste la répétabilité : une machine durcie doit pouvoir être reconstruite avec les mêmes règles et vérifiée dans le temps.
